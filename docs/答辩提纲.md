# 答辩与演示提纲

## 三分钟演示

1. 说明痛点与范围（20秒）：英文短信辅助分流，不承担诈骗认定。需求来自场景分析，没有编造访谈。
2. 运行 `python src/app.py`（20秒），输入默认中奖短链接样例，点击运行。指出分类、链接工具和策略节点；模型分数高仍然转人工。
3. 点击正常样例再运行（20秒），展示分数和字符特征贡献。
4. 点击中文边界样例（20秒），展示越界回退、未输出分数。
5. 展示metrics、模型比较图和错误文件（60秒）。多数类准确率87.94%但spam召回为零。字符LR测试F1=0.9333，词LR=0.9212。
6. 诚实讨论（40秒）：拒判消融未减少测试错误；静态链接只检查形态；历史英文数据不能证明对当代中文诈骗有效。

## 需要能够回答的问题

- Agent在哪里：固定任务状态机组织分类器与链接工具，记录执行过程，并处理越界、失败和人工复核。它不是开放式自主规划Agent。
- 为什么不用大模型：数据和任务适合文本分类，离线可复现、无需密钥；没有实验支撑跨任务优劣结论。
- TF-IDF是什么：词频经对数压缩，乘训练集IDF并L2归一化；测试不能参与词表和IDF拟合。
- 为什么用字符特征：对缩写和词形变化有一定共享，实测验证和测试F1优于词LR；字符解释可读性较弱。
- 为什么设balanced：类别不平衡，少数类权重更高；可能引入误报，须同时检查Precision。
- 参数从哪里来：候选配置固定，模型按验证F1选出，阈值按验证两侧纯度与最少样本约束选择；测试不用于调参。
- 为什么拒判没提升：正常侧99%纯度受到多数类影响，阈值选到0.49/0.50，测试没有分数落入中间区间；不是所有工程机制都会提高指标。
- 28条高相似样本意味着什么：规范化去重不能彻底解决模板近重复；需要来源/时间分组数据进一步评估。
- 0.95分数代表什么：分类器输出的spam分数，未经独立校准，不是95%诈骗概率。
- 0→1和1→0各是什么：0=ham、1=spam；前者误报，后者漏判。
- 人工复核算不算成功：不算正确分类，只减少自动覆盖；尚未评测人工处理质量或节省时间。
- 哪些是原创：工作流、数据处理、实验脚本、阈值策略、静态工具、解释和UI编排；学习器和语料明确复用并标注许可。
- AI辅助是否披露：报告已披露Codex参与代码、调试、实验和文档，提交者必须自行理解、核验并负责。
