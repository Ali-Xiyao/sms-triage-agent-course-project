# 答辩与演示提纲

## 三分钟演示

1. 说明历史英文短信辅助分流，课程LR提供统计证据，LLM选择工具并解释，用户最终确认。
2. 本地.env配置DeepSeek Flash，公开Key为空。打开界面选真实模式（会产生费用），运行中奖短链样例；无网时展示保存的真实截图和JSON，不把demo脚本称作真实模型。
3. 查看实际分类、链接、规则、提交轨迹及tool_call_id配对；查看T_CLASSIFY等证据。
4. 保持review并确认，pending_review变completed，导出JSON；不操作短信、不重训。
5. 展示F1=0.9333（1028条分类集）、52项软件测试、18/20真实任务匹配，解释三个数的不同含义。
6. 展示4条阈值解释错误及显式阈值修复后0条；承认local匹配19/20，没有证明LLM提高准确率或节省时间。

## 应解释的问题

- Agent实现：LLMAgent.run逐轮接收真实模型tool_calls，本地校验执行，匹配ID回传，直到证据齐全或到达预算；可变调用顺序不是仅改写分类文字。
- 真实调用：DeepSeek Flash非思考，20条构造任务前后两轮，每轮58次请求，另有浏览器演示；原始usage和response_id在results/llm。
- 为什么动作18/20而不是20/20：两条提示注入任务被LLM保守转review。即使看起来谨慎，也按预先目标记偏离。20/20指工具证据，不是任务或事实全对。
- 为什么local更高：这组任务主要对应固定规则，LLM多了主动保守判断并增加成本；解释与灵活调度价值仍需真人任务验证。
- 如何发现摘要错误：ID真实但描述阈值错误，说明引用完整不等于内容准确。传回0.49/0.50数值并约束解释后同组复测，仍不是泛化证据。
- Skill：外部K-Dense sklearn技能1.5用于开发复核、7项检查；docs/SKILL.md自编，运行时读取；sklearn库提供算法实现，三者不能混称。
- 防泄漏：规范化键先分组去重；词表和IDF仅fit训练集；每折Pipeline重拟合；测试用于最终报告，近似模板仍有限制。
- 原拒判无收益：0.49/0.50区间很窄，测试没有分数落入，原16条错误未减少；这是离线消融。
- 权限：无shell、网页访问、发信或删除；工具绑定原文、证据约束、最多6轮16工具。4条注入没有绕过，但不保证全面防御。
- AI使用：Codex参与方案、代码、实验、图表和报告起草修改，DeepSeek是运行组件；通过可复算数据、测试、哈希和轨迹核验，不宣称仅语言润色。

现场前亲自读experiment.py、core.py、llm_agent.py、真实Agent实验.md，并用自己的本地配置运行。避免在投影、报告或仓库显示密钥；公开存档可在不收费时查阅。

## 扩展结果要点

170次批量任务、493次真实请求。80条自然短信标签匹配local77/80、LLM75/80；两条新增复核与三条未减少的spam漏判均需解释。10条各三次动作一致，7条工具名序列一致；不能因temperature=0声称逐字确定。100条新增任务计划、样例哈希、原始用量和脱敏轨迹均在仓库，需区分原分类测试集与Agent留出任务、契约成功与类别正确。
