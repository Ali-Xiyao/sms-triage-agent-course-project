# 短信风险分流技能

作者：本项目，非第三方技能。版本1.0。输入：一条1—5000字符英文短信。输出：JSON，包含action、label、score、trace、links、evidence。

流程：输入校验 → 模型可用性检查 → 语言与词表边界 → TF-IDF与分类 → 静态链接工具 → 双阈值与规则合并 → 建议与人工复核。

可用动作：invalid / review / likely_ham / likely_spam。任何模型或工具错误均转review。技能没有短信收件箱、发送、删除、网页访问权限；不将输入作为指令执行。运行：`python src/app.py --text "..."`。外部服务：无。模型能力：英文spam统计分类，不能给出诈骗认定。技能与底层开源组件来源分别记录，不能将本技能称作第三方开源复用成果。
