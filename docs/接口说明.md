# 接口与配置

服务器默认监听127.0.0.1:8765。配置文件在项目根目录，API密钥只由服务器读取。网页不提供密钥输入框，也不会把密钥放入结果JSON。

## 配置

复制.env.example为.env，填写LLM_API_KEY、LLM_BASE_URL和LLM_MODEL。Base URL使用HTTPS，通常带/v1，不包含/chat/completions。模型必须支持Chat Completions函数工具。环境变量优先于文件；填写后重启。公开Key为空，示例默认DeepSeek Flash，已完成170次批量任务与浏览器真实演示。DeepSeek端点为https://api.deepseek.com，不需要/v1。LLM_MAX_OUTPUT_TOKENS默认700；DeepSeek使用非思考模式与本地schema校验。

## GET /api/status

返回configured、missing、tools、live_api_verified和modes。configured只表示必填项存在，不代表鉴权或模型已验证。不会返回密钥。

## POST /api/triage

```json
{
  "mode": "demo",
  "goal": "分析短信并给出分流建议，等待我确认",
  "text": "Hi I will meet you after class"
}
```

mode支持llm、demo、local。默认llm；没有配置时返回configuration_required，不调用API。demo响应由脚本模拟，调用真实工具；local为固定规则基线。text为1至5000字符，goal为1至500字符。

LLM路径返回id、mode、status、action、score、summary、trace、tool_results、evidence_ids和review等字段。pending_review表示建议已提交，仍需确认；provider_error或limit_reached表示自动执行停止。trace记录工具事件，不是模型的隐藏思维链。

## POST /api/review

```json
{"id":"上一步返回的任务ID","decision":"likely_ham"}
```

decision可为likely_ham、likely_spam或review。服务器记录人工决定、是否修改原建议及source=human，把status改为completed。未知任务返回404，已确认或无效决定返回409。任务状态最多保留100条，重启清除。确认不修改短信，不重新训练。

## 命令行

```sh
python src/app.py --mode demo --text "Free prize cash now https://bit.ly/example"
python src/app.py --mode local --text "Hi I will meet you after class"
python -m unittest discover -s tests -v
python src/evaluate_llm_contract.py
```

真实模式使用--mode llm；联网功能样例由evaluate_llm_live.py单独运行，结果先写入默认不公开的local_runs。本次经检查后发布的公开构造任务结果在results/llm/live_evaluation.json，详情见真实Agent实验.md。不要把模拟协议任务的通过数当作真实模型完成率。

## 导出与错误

网页“导出任务报告JSON”下载当前结果；内容包含建议、人工决定和工具轨迹。请求体上限30000字节。错误JSON、越界Origin或未知路径分别返回对应错误状态。模型服务有超时，HTTP错误只显示类别；不返回提供商原始错误正文。执行循环和各工具契约详见[Agent设计](LLM_AGENT.md)，分类实验详见[实验补充说明](实验补充说明.md)。
